# seoul-realestate

서울 자치구 한 곳의 한 달치 부동산 매매 실거래를 모아 시세를 정리하고, 이상 거래 후보를 골라내는 Claude Code agent 구성을 소개하는 한 페이지입니다. Claude Code 실습 과정의 캡스톤(R1-B) 결과물입니다.

페이지는 GitHub Pages로 공개합니다. 저장소 Settings → Pages에 나오는 주소로 열 수 있습니다.

## 페이지 구성

1. **맡긴 업무**: 자치구와 달을 받아 매매 시세를 정리하고 이상 거래 후보를 고른다.
2. **agent 역할과 흐름**: `price-summarizer`(시세 정리)와 `anomaly-checker`(이상 거래 검토, 읽기 전용)가 `search_trades` MCP 도구 하나로 데이터를 받는 흐름.
3. **가드레일**: 키 노출을 막는 `key-guard`, 허용 주소 밖 호출을 막는 `net-guard` 등 훅과 권한 설정.
4. **실제 호출과 판정**: 강남구 2026년 11월 실거래 34건으로 만든 시세 요약과 이상 거래 후보.
5. **막힌 장면**: 규칙과 훅이 요청을 실제로 막은 사례.

## 데이터와 표기 원칙

- 출처: 서울 열린데이터광장 「서울시 부동산 실거래가 정보」(`tbLnOpendataRtmsV`). 금액 단위는 만원, 면적은 ㎡입니다.
- 위치는 법정동까지만 적고 본번, 부번, 건물명은 쓰지 않았습니다.
- API 키는 페이지와 저장소 어디에도 들어 있지 않습니다.
