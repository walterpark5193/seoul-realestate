key-guard.sh

연결

UserPromptSubmit. PreToolUse: Read, Bash, Write, Edit, WebFetch

등록된 서울 API 키 값 그대로. SEOUL_API_KEY를 값과 함께 적는 모양. Open API URL 경로 속 키. 키가 저장된 사용자 설정 파일 이름. 프로세스 환경 변수를 엿보는 명령 모양. git commit이면 staged diff도 검사합니다. jq가 없거나 해석에 실패하거나 grep이 오류를 내면 모두 차단합니다(fail-closed).

net-guard.sh

연결

PreToolUse: Bash, WebFetch

입력에서 http(s)://호스트를 전부 뽑아 사용자 정보와 포트를 떼고 소문자로 비교합니다. openapi.seoul.go.kr이 아닌 호스트가 하나라도 있으면 차단합니다. 주소 부분에 셸 문자가 섞이거나 호스트가 비어 있어도 막습니다. 다만 글자 검사라 셸이 따옴표를 합쳐 만드는 주소는 보지 못하므로 보조 경보로 둡니다.

permissions.deny

연결

도구 호출 전, 훅보다 먼저

Read(사용자 설정 파일): 키가 저장된 파일은 Read 자체를 거부합니다. WebSearch: URL이 없어 훅이 볼 수 없는 외부 검색을 도구 단위로 거부합니다. WebFetch: 데이터는 search_trades로만 가져오므로 웹 가져오기도 도구 단위로 거부합니다. 주소를 어떻게 꾸며도 통과하지 못합니다. mydata 트랙용으로 원본 데이터(mydata/raw) 읽기, 이름에 transactions가 든 거래 원장 읽기, pseudo 폴더 수정도 거부합니다.

path-guard.sh

연결

PreToolUse: Read, Grep, Glob, Bash

이름에 transactions가 든 거래 원장과 raw/ 원본 경로. 심볼릭 링크는 realpath로 풀어 다시 검사합니다. Bash는 glob, 확장 문자와 데이터 경로의 조합을 한꺼번에 차단합니다.

dlp-guard.sh

연결

UserPromptSubmit. PreToolUse: Write, Edit, NotebookEdit, Bash

주민번호, 카드번호, 휴대폰, 계좌번호, CI 토큰, AWS 액세스 키 모양. 고객용 시트 경로(out/sheets/)에서는 고객 ID 모양도 차단합니다.

raw-guard.sh

대체됨

연결하지 않음

mydata/raw, raw/ 접근. path-guard의 단순판이라, 같은 경로를 더 넓게 막는 path-guard를 대신 연결했습니다.

path-guard와 dlp-guard는 mydata 트랙(고객 데이터)용 가드로, key-guard, net-guard와 함께 연결돼 있습니다. raw-guard는 path-guard의 단순판이라 연결하지 않았습니다.

훅의 matcher는 Read, Bash 같은 기본 도구만 대상으로 합니다. 그래서 search_trades 같은 MCP 도구 호출은 훅이 검사하지 않습니다. 그 호출은 agent의 tools 목록과 permissions.deny가 제한하고, 키는 MCP 서버의 환경 변수에만 있어 호출 인자에 나타나지 않습니다.

Bash의 네트워크 호출을 구조적으로 막으려면 Claude Code 샌드박스의 네트워크 허용 목록(sandbox.network.allowedDomains)이 필요합니다. 이 환경에는 샌드박스에 필요한 bubblewrap과 socat이 없어 아직 켜지 않았고, 그 전까지 net-guard가 보조 경보 역할을 합니다.

가격은 정상 범위이고 취소 사실이 사유입니다. 자곡동 아파트가 이 1건뿐이라 동 안 비교는 할 수 없고, 다시 신고된 건은 이번 조회에 없습니다.
5 논현동, 취소 뒤 재신고로 추정
같은 날, 같은 금액, 면적, 층으로 취소일이 없는 거래가 1건 더 있습니다. 정정 신고일 가능성이 큽니다.

"이상 거래 후보"는 더 확인할 거래라는 뜻이며 위법 판단이 아닙니다. anomaly-checker는 취소 2건을 포함해 아파트 중앙값 3,179.5(14건)를 썼고 price-summarizer는 취소를 빼 3,456(12건)을 냈습니다. 두 표의 중앙값이 다른 이유입니다.

mock에서는 용도마다 3건이라 보이지 않던 문제가 실데이터에서 드러났습니다. 아파트 ㎡당 가격이 1,027부터 6,190까지 6배 벌어져 있어 용도 전체 중앙값 하나로 자르면 대치동 중소형의 정상 거래가 후보로 잡힙니다. 그래서 법정동 안 비교를 함께 적게 했고, 동 안 표본도 3~4건이라 다음 단계는 면적대와 건축연도별 비교입니다.

curl로 example.com 부르기

같은 세션에서 curl로 example.com 첫 줄을 가져오라는 요청이 있었습니다. CLAUDE.md의 호출 대상 규칙에 따라 실행하지 않았고, 사용자가 직접 실행하는 길을 안내했습니다.

막은 것: CLAUDE.md 규칙. 같은 명령을 net-guard.sh에 넣으면 차단되는 것을 tests/test_hooks.py로 확인
